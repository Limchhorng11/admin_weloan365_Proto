# Brand assets

Drop the app logo here so it shows everywhere automatically.

- **`logo.png`** — the square icon mark (transparent PNG recommended, e.g. 256×256).
  Used by `components/brand-logo.tsx` in the sidebar, login, and forgot-password
  screens. Until this file exists, the UI falls back to the "W" mark.

To rebrand the whole app, just replace `logo.png`.
